카지노 영상분석

2025.11 ~ 진행 중 · 고객사 2곳 폐쇄망 PoC → 스마트테이블 확장

코드·데이터 반출입마다 담당자를 거쳐야 하는 폐쇄망 환경에서 3주간 현장에 상주하며 칩·카드 인식 파이프라인을 처음부터 구축했습니다. BMT·데모를 마친 뒤 신규 고객사 스마트테이블 프로젝트로 확장됐습니다.

기간
2025.11 ~ 진행 중 (고객사 2곳)
환경
폐쇄망 PoC 3주 · 현장 상주 — 코드·데이터 반출입마다 담당자 승인 필요
역할
칩·카드 인식 파이프라인 설계·구현, 좌표계 변환, 라벨링 도구 자체 제작, BMT·데모 대응, 치팅 탐지 알고리즘 설계
기술
Homography / Piecewise Affine · Keypoint 검출 · Segmentation · 영상처리(이진화, 원통 전개, line 검출)
PoC 폐쇄망 3주 현장 상주 · 파이프라인 신규 구축
전달 BMT · 데모 완료 고객 요구 포맷 대응 포함
확장 치팅 탐지 1차 신규 고객사 스마트테이블 프로젝트
Context

3주, 폐쇄망, 백지 상태

기존 자산을 가져다 쓸 수 없고, 만든 결과를 바깥으로 꺼내 확인할 수도 없는 조건에서 칩·카드 인식 파이프라인을 처음부터 세워야 했습니다.

현장은 내부망이었습니다. 코드 한 줄, 데이터 한 장을 넣고 빼는 데 매번 담당자 승인을 거쳐야 했고, 평소처럼 외부 사전학습 자산이나 도구를 자유롭게 끌어다 쓸 수 없었습니다. 3주 안에 동작하는 파이프라인과 BMT·데모까지 만들어야 하는 일정이었으므로, 반출입 횟수를 최소화하도록 작업 순서를 설계하는 것부터가 과제였습니다.

기술적으로는 두 축이었습니다. 하나는 사선으로 설치된 카메라 영상을 테이블 좌표계로 옮기는 문제, 다른 하나는 쌓여 있는 칩의 개수와 카드를 세는 문제입니다.

Work

문제 → 접근 → 결과

01 — 사선 카메라 → 탑뷰 좌표계 변환

문제

카메라가 테이블 위쪽 사선에 설치돼 있어, 어느 베팅 구역에 칩이 놓였는지 판정하려면 영상 좌표를 테이블 평면 좌표로 옮겨야 했습니다.

접근

먼저 단일 Homography를 적용했지만, 베팅 영역이 곡면 형태라 가장자리에서 왜곡이 남았습니다. 평면 가정 자체가 맞지 않는 구간이었습니다. keypoint 기반으로 영역을 먼저 검출한 뒤 구간별로 Piecewise Affine 변환을 적용해 보정했습니다.

결과

곡면 베팅 영역에서도 구역 판정이 가능한 탑뷰 좌표계를 확보했습니다.

02 — 칩 카운팅

쌓인 칩은 옆면 줄무늬로 개수를 세야 하는데, 조명·각도·칩 색상에 따라 경계가 흐려집니다. 단일 정답이 없는 문제라 이진화, 원통 펼치기(unwrapping), line 검출 등 여러 영상처리 접근을 구현해 같은 데이터에서 비교했습니다.

03 — 라벨링 툴 자체 제작과 반복 사이클

문제

폐쇄망이라 외부 라벨링 서비스를 쓸 수 없었고, segmentation 라벨을 빠르게 만들 수단이 없었습니다.

접근

segmentation 라벨링 툴을 자체 제작하고, [소량 라벨링 → 학습 → 추론 → 재라벨링] 사이클을 운영했습니다. 모델이 만든 추론 결과를 수정하는 방식이라 라벨링 비용이 회차마다 줄어듭니다.

결과

제한된 인원·기간 안에서 학습 가능한 데이터를 확보했고, 이후 재라벨링도 같은 루프로 처리했습니다.

04 — BMT · 데모

고객이 요구한 출력 포맷 대응까지 포함해 BMT와 데모를 완료했습니다. 폐쇄망 조건에서 3주 만에 파이프라인 구축부터 시연까지 끝낸 결과가 다음 단계로 이어졌습니다.

05 — 스마트테이블 프로젝트로 확장 진행 중

PoC 이후 신규 고객사의 스마트테이블 프로젝트로 확장됐습니다. 칩·카드 인식 위에 행위 판정 레이어를 올리는 방향입니다.

  • 치팅 탐지 알고리즘 1차 완성본 전달 — LATE 베팅(베팅 마감 후 칩 추가), 칩 이동·회수, 카드 치팅 등 유형별 판정 로직
  • 현장 CCTV 설치 기반 데이터 수집 설계 진행 중 — 실제 운영 환경의 카메라 배치에 맞춘 수집 조건 정의
