과제
PAR — CCTV 속 사람의 성별 · 나이대 · 체형 · 머리 · 상하의 · 신발 · 소지품 · 행동 등 이진 속성 38개 / ReID — 여러 카메라에서 같은 사람 찾기(검색 · 동선 추적)
데이터
공개: Market-1501 · DukeMTMC-reID / PA-100K · RAPv2 · PETA · MSP60K 합본. 사내: 실내외 카메라에서 자동 수집한 사람 crop(여름), 사람이 검수한 평가셋
모델
ReID — PE-Core-L/14 + CLIP-ReID 식 2단계 학습, 입력 336×112 / PAR — PE-Core-B/16 + 속성별 어텐션 풀 질의 + 텍스트로 초기화한 분류기
흐름
08.31 인수 → 09.30 벤치 재현 → 10.02~05 집중 고도화 → 10.12 후속 실험 → 배포 검토
역할
단독 담당 — 실험 설계 · 판정 기준 사전 등록 · 결과 검수 · 문서화, 실행은 자동화 에이전트로 병렬화
핵심

성능보다 먼저 정한 여섯 가지

  1. 01
    라이선스부터 — 백본 교체 기존 백본의 사전학습 데이터가 비상업 조건인 것을 발견하고 Apache-2.0 백본(Perception Encoder)으로 전환. 후보로 SigLIP2 · DINOv2 · 기존 백본 재학습도 비교.
    Apache-2.0
  2. 02
    속도 상한을 먼저 정하고 입력 크기로 맞춤 PyTorch 기준 기존 대비 1.5배 이내를 넘지 않게 ReID 입력을 336×112로 줄임. 배포 형식인 ONNX fp16에서는 오히려 기존보다 빠름.
    ONNX ×1.5 · ×2
  3. 03
    판정 기준은 결과보다 먼저 무엇을 넘으면 채택인지 실험 전에 기록. 2~3시드 평균, 마지막 epoch만 사용 — 벤치마크 점수로 epoch를 고르지 않음.
    사전 등록
  4. 04
    누출 차단 평가에 쓰는 날짜 · 인물, 그리고 외형이 가까운 사람까지 학습에서 제외.
  5. 05
    의사 라벨은 두 대 이상 카메라에 걸친 군집만 라벨 없는 여름 데이터를 배포 모델 특징으로 날짜 안에서 카메라 간 군집. 임계값은 자동 얼굴 라벨로 맞추고, 사람 검수(무작위 40 ID)로 정밀도를 확인.
    정밀도 ≥ 97.5%
  6. 06
    PAR — 텍스트는 학습 때만 속성마다 이미지에서 따로 질의하는 어텐션 풀과, 속성 이름의 텍스트 임베딩으로 초기화한 분류기. 추론은 이미지만 써서 배포 형상은 그대로.

시행착오

막힌 것 → 바꾼 것

  1. 01
    여름 데이터에 라벨이 없음 → 배포 모델 특징으로 카메라 간 군집 의사 라벨, 자동 얼굴 라벨로 임계값을 맞추고 사람이 무작위 40 ID를 검수(정밀도 97.5% 이상).
  2. 02
    평가가 같은 건물 안이라 일반화를 알 수 없음 → ‘처음 보는 카메라’(특정 카메라를 빼고 학습) · ‘처음 보는 현장’(공개셋만 학습) 대리 시험을 더해 이점이 유지되는지 확인.
  3. 03
    시드 흔들림을 작게 잡고 있었음 — 샘플러가 epoch로만 섞임 → 데이터 순서까지 시드에 묶어 다시 학습, 결론이 유지됨을 확인. 이 과정에서 라이선스 위험도 발견해 백본을 바꿈.
