키포인트 가림(visibility) 학습 — 합성 가림에서 학습 라벨 오류까지

2026.09 ~ 진행 중 기본 모델 교체는 실사용 시험 후 결정

손이나 컵으로 입을 가려도 웹캠 얼굴 · 사람 7점 포즈 모델은 입꼬리를 ‘보임’으로 냈습니다. 합성 가림으로 공개 실사 가림 판별력은 끌어올렸지만 실제 손 가림은 계속 놓쳤고, 원인을 하나씩 걷어낸 끝에 제품 도메인 학습 얼굴의 9.6%가 손 가림인데 ‘보임’으로 라벨돼 있던 것을 찾았습니다.

입가림 오라벨 후보 9.6% 웹캠 착석 환경 학습 얼굴 중
후보 검수 확정률 95.8% 먼저 검수한 후보 중 실제 입가림
실사 가림 판별 wiROC 0.637 → 0.894 공개 COFW · 합성 가림 학습 후
손 입가림 억제 0.998 → 0.221 모든 모델이 놓치던 자세의 입꼬리 신뢰도(예)
모델
YOLO11n 얼굴 · 사람 7점 포즈(눈 · 입꼬리 · 코 · 어깨 · 팔꿈치 · 손목) — 화면이동탐지에서 사람 영역을 빼는 데 쓰이고, 키포인트마다 보임 신뢰도를 냄
데이터
실물 가리개 조각으로 만든 합성 가림 8만 장 · 상업 이용 가능한 공개 데이터에서 다시 뽑은 손 조각 1,206개(전수 육안 검수 2회) · 공개 실사 가림 데이터 COFW
역할
실험 설계 · 가림 합성 데이터와 손 라이브러리 구축 · 라벨 감사 · 검수 화면 개발 · 학습 · 평가
이어진 것
같은 모델의 CPU 경량화 → 비정사각 입력 · 라벨 수정 모델 → 화면이동탐지의 사람 검출
추적

안 풀리는 이유를 하나씩 걷어냄

  1. 01
    합성 가림 8만 장 — 공개 실사에서도 통했다 손 · 컵 · 휴대폰 같은 실물 가리개로 키포인트를 조준해 가리고, 가린 점만 ‘안 보임’으로. 생성기를 외운 게 아님을 공개 COFW로 확인(wiROC 0.637 → 0.894), 위치 오차 · 박스 탐지 회귀 없음.
    wiROC 0.894
  2. 02
    그래도 웹캠 앞 손 가림은 그대로 — 큰 얼굴이 분포 밖 같은 크롭에서 입력만 낮추자(얼굴 400 → 200px) 손가림 억제율 0.452 → 0.830. 정보를 줄였는데 오른 것이라 분포 문제.
    0.45 → 0.83
  3. 03
    피부톤 가설은 인과 실험으로 기각 손 색을 얼굴 피부톤으로 바꿔도 손만 약한 현상이 그대로 → 색 맞춤 증강은 착수하지 않음.
  4. 04
    손 조각만 작고 반투명했다 불투명 비율 0.57(다른 가리개 0.81~0.82). 얼굴에 닿은 손은 통째로 버리는 규칙 탓에 ‘손으로 얼굴을 가린’ 조각이 0. 공개 데이터에서 다시 뽑아 재구축 — 회귀는 없었지만 실사 손 억제는 여전히 낮음.
  5. 05
    진짜 뿌리 — 제품 도메인 학습 라벨 합성 검수 중, 놓친 가림이 붙인 손이 아니라 원본에 찍힌 실제 손인 것을 발견. 입꼬리 근처에 입이 검출되지 않는 신호로 규모를 재니 학습 얼굴의 9.6%. 합성이 ‘가리면 안 보임’을 가르치는 동안 실제 사진 수천 장이 ‘가려도 보임’을 가르치고 있었다.
    9.6%
  6. 06
    검수 화면 → 라벨 수정 재학습 보임 · 가림 · 불명 단추와 키보드 흐름. 모델 예측 미리 채우기가 기본값 편향을 만들어 기본을 ‘불명’으로. 검수분은 고치고 미검수 후보는 빼서 재학습 → 모든 모델이 놓치던 손 입가림 네 자세를 처음으로 억제.
    0.998 → 0.221
검증

점수를 믿지 않은 세 번

  1. 01
    검증셋에 가림 라벨이 0개 가림을 잘 배울수록 검증 손실이 오히려 올라감 → 그 지표는 판정에서 뺌.
  2. 02
    ‘mAP 0.99’의 정체 군중 · 일반 · 웹캠이 섞인 검증셋에서 0.97을 넘는 건 웹캠 부분 하나뿐이고 전체는 0.81. 얼굴 정답 대부분이 군중의 아주 작은 얼굴이라 평균이 도메인 성능을 말해 주지 않았다.
  3. 03
    검증 인물이 학습 인물과 100% 겹침 웹캠 쪽 만점은 같은 사람 · 같은 책상을 외운 값. 판정을 학습에서 뺀 8명 홀드아웃과 실사용 시험으로 옮김.
결과

이득은 대부분 라벨 수정에서

  1. 01
    이득은 학습 길이가 아니라 라벨 수정에서 학습에서 뺀 8명 홀드아웃에서, 라벨을 고친 모델은 기존 모델과 비슷한 입꼬리 가림 recall을 더 적은 오억제로 냄. 같은 길이로 다시 학습해 비교해 보니 이득 대부분이 라벨 수정에서 나옴.
    라벨 수정
  2. 02
    떨어진 지표를 오진하지 않기 라벨 수정 뒤 얼굴 지표 급락이 가림 억제의 부작용처럼 보였지만, 억제를 안 배운 눈 · 코도 똑같이 떨어졌다. 원인은 16px 미만 작은 얼굴 검출 — 기존 모델도 같은 수준이라 별도 과제로 분리.
  3. 03
    기각한 것 얼굴 전용 1클래스(입꼬리를 눈과 맞바꿈), 포즈 모델의 P5 제거(관절 정밀도 −14.5%, 입꼬리 오억제 급증 — 탐지 모델에서는 채택했지만 포즈 모델에서는 대가가 큼) → 경량화 후보도 가시성 축을 먼저 통과해야 한다는 기준.
  4. 남음
    눈 가림 · 검증셋 라벨 · 작은 얼굴 사람이 검수한 눈 가림은 입꼬리의 1/44뿐이라 눈 가림은 아직 못 배움. 검증셋 가림 라벨 수정, 작은 얼굴 검출, 실사용 시험 뒤 기본 모델 교체가 남음.

사내 데이터는 비율 · 상대 비교로만 적었고, 사람 얼굴이 나오는 자료는 싣지 않았습니다. COFW는 공개 데이터입니다.
