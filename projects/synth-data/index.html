웹캠 촬영기기 합성 데이터 — 시뮬레이터에서 실사화까지

2026.10.16 ~ 10.20 · 5일 파일럿 파일럿 완료 · 방향 결정 대기

폰을 든 웹캠 영상은 거의 없고, 있어도 얼굴이 섞여 모으기 어렵습니다. 그래서 장면을 3D로 만들고, 라벨은 기하에서 뽑고, 사람은 실사화해서 실데이터에 섞어 봤습니다. 결론은 사실감보다 박스 기하 — 실사화의 추가 이득은 재현되지 않았고, 렌더의 해는 구도를 실측 분포에 맞추자 사라졌습니다.

기간 5 일 10.16 설계 → 10.20 파일럿 끝
합성 조합 16 가지 대부분 시드 8회 반복
짝 비교 30여 쌍 같은 장의 렌더본 ↔ 실사화본
구조 보존 통과율 ×3 인체 자산만 바꿔서(합성 데이터 기준)
목표
웹캠 앞에서 폰 · 카메라 · 태블릿을 든 사람 검출 — 드문 기종 · 파지 · 거리를 원하는 만큼
도구
Three.js 한 페이지 스튜디오 + 헤드리스 브라우저 배치 생성(같은 시드면 같은 결과) · 깊이 조건 디퓨전 인페인팅
자산
공개 인체 28종(MIT) · 실내 HDRI(CC0) · 절차 생성 + 공개 3D 기기. 학습 금지 조항 · 비상업 라이선스 자산은 쓰지 않음
출발점
카지노 과제의 테이블 시야 시뮬레이터에서 레이아웃 · 광학 프리셋을 재사용
만드는 법

여섯 단계, 단계마다 정한 것

  1. 01
    장면 — 브라우저 한 페이지 스튜디오 라벨 규약과 검수를 눈으로 바로 확정하려고 Blender 대신 Three.js로. 헤드리스로 배치 생성하고, 같은 시드면 바이트까지 같은 결과.
    재현 가능
  2. 02
    사람 — 공개 인체 28종 · 파지 자세 8종 처음 쓴 마네킹 자산에 ML 학습 금지 조항 → MIT 인체로 교체. 손 IK로 쥐는 자세를 만들고, 렌즈를 가리는 자세는 아예 만들지 않음.
    라이선스 확인
  3. 03
    기기 — 평평한 상자에서 재질 있는 모델로 절차 생성 기기와 공개 3D 모델을 섞어 유리 · 금속 · 카메라 섬 재질까지.
  4. 04
    촬영 · 자동 라벨 — 라벨은 3D 기하에서 실제 웹캠 화각 프리셋, 실내 실사 HDRI 배경. 인스턴스 ID 패스에서 박스 · 마스크 · 깊이를 뽑고, 폰은 후면 렌즈가 있는 상단 띠만 박스. 렌즈가 가려지거나 잘린 장은 통째로 빼고 웹캠 열화를 입힘.
    자동 라벨
  5. 05
    실사화 — 깊이 조건 인페인팅 2단계 RGB만 넣은 렌더→실사 변환은 세부가 깨져서 깊이 같은 구조 정보를 조건으로. 사람 → 기기(약하게) 순서, 배경은 그대로. 마스크 IoU · 렌즈 보임 · 없는 기기 생성 검사를 모두 통과한 장만 씀.
    검수 3종
  6. 06
    학습 · 비교 — 외관 효과만 떼어 보기 실데이터에 섞어 학습. 같은 장의 렌더본과 실사화본을 짝지어 비교해 외관 효과만 분리하고, 시드 8회로 반복.
    짝 비교
결과

사실감보다 박스 기하

  1. 01
    실사화 품질은 올라왔다 사람은 사진 수준, 기기는 재질 좋은 자산으로 바꾼 뒤 약한 세기로도 제품처럼 보임. 인체 자산만 바꿨는데 구조 보존 검사 통과율이 약 3배.
    통과율 ×3
  2. 02
    실데이터만 쓴 기준을 유의하게 넘은 조합은 없었다 실데이터가 적은 조건의 파일럿 — 합성 조합 16가지, 대부분 시드 8회, 짝 비교 30여 쌍.
    16조합 × 8시드
  3. 03
    렌더만 넣으면 조금 해로웠다 — 원인은 사실감이 아니라 기하 박스 기하와 구도를 실측 분포에 맞추자 해가 사라짐. 실사화로 얻는 추가 이득은 재현되지 않음.
  4. 다음
    드문 장면만 따로 재기 후보: 드문 장면 전용 평가, 실데이터가 더 적은 조건, 실제 웹캠 영상에서 기종만 바꾸는 영상 경로 — 방향 결정 대기.
시행착오

막힌 것 → 바꾼 것

  1. 01
    실사화가 마네킹 모양까지 그대로 따라 그림 → 사람 형태의 인체 자산으로 교체.
  2. 02
    그대로 둔 기기가 평평한 판처럼 보임 → ‘픽셀 보존’을 ‘형상 보존 + 외관 재생성 + 사후 검수’로.
  3. 03
    배경이 한 가지 홈오피스로 수렴하고, ‘폰 없음’ 억제 문구가 오히려 없는 폰을 만듦 → 배경은 그대로 두고 그 문구를 뺌.

이 페이지의 숫자는 합성 데이터로 잰 것과 비교 설계(조합 · 시드 · 짝 수)만 적었습니다. 회사 데이터로 잰 성능 수치와 화면은 공개하지 않습니다.
